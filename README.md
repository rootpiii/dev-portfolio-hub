# Minimalist Software Developer Portfolio

A modern, gorgeous, and responsive software developer portfolio built with React, TypeScript, and Tailwind CSS.

## Features
- Hero section with bio, status badge, and quick stats
- Interactive Projects showcase with tag filtering and modal details
- Live simulated terminal for developer commands (`help`, `skills`, `projects`, `clear`)
- Skills matrix categorized by Frontend, Backend, DevOps, and Tools
- Functional Contact Form with instant success feedback and toast notifications
- Dark mode support and smooth micro-animations
